# LLM Start Here

1. Read `AGENTS.md` in full.
2. Read `Academic_Platform_PRD.md` for the product requirements.
3. Load `docs/llm/context-map.md` to find which docs apply to the current task type.
4. Follow `.ai/team/workflow.md` for multi-role tasks (intake -> analysis -> planning ->
   execution -> handoff).
5. Use the matching role file in `.ai/team/roles/` and, if orchestrating sub-agents, the matching
   definition in `.claude/agents/`.
6. Report using the Task Output Contract in `AGENTS.md`.
